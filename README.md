| File type	 |   Recommended location	|        Example |
| :---         |     :---      |         :--- |
| Reusable React components	 |         src/components/	     |  ChartContainer.jsx |
| Project-specific React components	| projects/bar-chart/	 |         BarChart.jsx |
| Shared images imported into React	|  src/assets/	         |         logo.svg |
| Static public images |              public/images/	       |       pokemon-logo.png |
| Project-specific datasets	|        projects/bar-chart/data/	 |   sales.csv |
| Shared CSS	 |                       src/styles/	   |               global.css |
| Project-specific CSS	 |             Project folder	|            style.css |

For D3, keep small datasets close to their charts. If loading a CSV using d3.csv() at runtime, however, **it must be served as a public asset or explicitly included through Vite's asset handling**. Merely placing a CSV next to a JSX component doesn't make it available as a runtime URL.

For images imported into React, Vite processes the files and handles their production URLs:

```JavaScript
import logo from "../../src/assets/logo.svg";

function Header() {
  return <img src={logo} alt="Logo" />;
}
```
**The folder structure alone doesn't tell Vite which pages to build. Your vite.config.js must include the HTML entry points for the individual projects.**
